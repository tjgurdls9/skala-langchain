# MediaPipe resources

These files are served locally so webcam frames stay in the browser.

- JavaScript / WASM: `@mediapipe/tasks-vision` 1.0.1, downloaded from the official npm registry: https://registry.npmjs.org/@mediapipe/tasks-vision/-/tasks-vision-1.0.1.tgz
- Gesture model: https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task
- Guide: https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer
- Upstream source and license: https://github.com/google-ai-edge/mediapipe

The application uses the supplied gesture classes and hand landmarks; it does not train or identify a person.
